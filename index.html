Ark Server Assist — Privacy Policy

1. Data We Collect

Our Discord bot processes minimal user data required for its core functionality. This includes:

  • Discord User IDs, Guild IDs, and Channel IDs.
  • Message content strictly in real-time memory to detect command prefixes (e.g., !) and specific server keywords ("when wipe?", "what ip to connect?").

2. How We Use Data

The data is used exclusively to:

  • Operate the in-game linked support ticket system.
  • Provide automated text answers to players' questions.
  • Execute moderation actions via commands like !spam.

3. Data Storage and Retention

We do not store message content data off-platform. All message data is processed in volatile memory and instantly discarded. Server configuration preferences and active ticket states are stored securely and can be removed upon request.

4. Data Deletion

Users can request the removal of any cached data related to their account or guild by contacting the bot developers directly via our support server. https://discord.gg/tM3NS6jjzf
